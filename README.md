# Retirement_City_Dashboard
This Python code creates a dashboard using the dash package to display an interactive graph of US News' "Best Places to Retire in the U.S. in 2025-2026" website, found [here](https://realestate.usnews.com/places/rankings/best-places-to-retire). The data was scraped manually into a CSV file, found in `usnews_retirement_places.csv`. To make the dashboard run, do the following:
1. Make sure that the packages `dash`, `numpy`, `pandas`, and `plotly` are installed 
2. Run the following command in your terminal
    ```
    $ python path/to/retirement_places_dashboard.py
    ```
3. Follow the URL given in the output (e.g., `Dash is running on http://127.0.0.1:8050/`)
